# # Fitbit Fitness Tracker Data Analysis Using R

## Project Overview

This project explores fitness-tracking data to understand patterns in users' physical activity and health-related behaviours. Using R and data visualization techniques, the analysis investigates information recorded by Fitbit devices to identify trends that could help stakeholders better understand how people use fitness-tracking technology.

The project demonstrates practical experience in data analysis, data preparation, exploratory analysis, and visualization using R.

## Business Problem

Fitness technology companies need to understand how consumers interact with wearable devices and which activity patterns can inform product development and user engagement strategies.

This project explores the following questions:

- What patterns can be identified in users' fitness-tracking data?
- What does the available data reveal about users' activity and daily habits?
- How can data visualization help communicate these patterns and support better-informed decisions?

The analysis is exploratory and focuses on identifying patterns within the available dataset.

## Dataset

The project uses Fitbit fitness-tracker data accessed through Kaggle.

The broader Fitbit Fitness Tracker dataset contains personal fitness-tracking information contributed by a small group of users. Depending on the files selected for analysis, the available data may include daily activity, steps, calories, and sleep-related measurements.
